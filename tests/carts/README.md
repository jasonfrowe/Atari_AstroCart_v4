# Test carts

The cart images that `sim/multicart/run.sh` loads through the menu code, one
or more for each kind of cart the regression covers.

**Note:** Cart ROM images are copyrighted by their respective authors and
publishers and are **not distributed** with this repository. To run the
multicart simulations locally, obtain these `.a78` files and place them in this
directory:

| File | Kind |
|---|---|
| `Choplifter_NTSC.a78`, `Food Fight (NTSC) (Atari) (1987) (E64A5CDE).a78` | 32K linear |
| `astrowing.a78` | 48K linear, POKEY at `$0450` |
| `Commando (NTSC) (Atari) (1989) (CD1A98C5).a78` | 128K SuperGame with bank 6 at `$4000`, POKEY at `$4000` |
| `Impossible Mission (NTSC) (Atari) (1987) (3B1F2F47).a78`, `Jinks (NTSC) (Atari) (1989) (0818D8CD).a78` | 128K SuperGame with 16K RAM |
| `Tiger-Heli 7800 (World) (NTSC) (Aftermarket).a78` | 144K SuperGame with ROM at `$4000`, POKEY at `$0450` |
| `ARTI_Final_digital_edition_jan24_1.1.a78` | 256K SuperGame with 16K RAM, POKEY at `$0450` |
